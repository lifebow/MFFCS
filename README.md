# MFFCS
Assignment: Mathematical Foundations for Computer Science

## Reference

This repository builds on the material in Chapters 5.1–5.3 of  
[Dive into Deep Learning](https://d2l.ai/chapter_multilayer-perceptrons/) (D2L).

## What’s different
We have expanded the original theory with the examples, providing
step-by-step explanations inside each Jupyter notebook and a fully commented
implementation script.  

## Recommended order of read

1. **MLP_Overview.ipynb** – high-level intuition and notation.
2. **MLP_Forward_Backward.ipynb** – detailed forward and backward-pass walkthroughs with examples.
3. **MLP_Implementation.ipynb** – clean reference implementation with line-by-line
   explanations.

Start with the *Overview*, proceed to *Forward_Backward*, and finish with
*Implementation* for the smoothest learning experience.
